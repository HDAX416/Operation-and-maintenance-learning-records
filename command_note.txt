更新软件包索引	sudo yum makecache	sudo apt update
安装软件（比如 Nginx）	sudo yum install nginx -y	sudo apt install nginx -y 
卸载软件（保留配置）	sudo yum remove nginx -y	sudo apt remove nginx -y
卸载软件（删除所有配置）	sudo yum erase nginx -y	sudo apt purge nginx -y
查看软件安装路径	rpm -ql nginx	dpkg -L nginx
查看系统已安装包	rpm -qa	dpkg -l
启动服务（比如 Nginx）	sudo systemctl start nginx	sudo systemctl start nginx
设为开机自启	sudo systemctl enable nginx	sudo systemctl enable nginx
停止服务	sudo systemctl stop nginx	sudo systemctl stop nginx
查看服务状态	sudo systemctl status nginx	sudo systemctl status nginx
重启服务	sudo systemctl restart nginx	sudo systemctl restart nginx

系统目录结构
完全一致！/etc（配置文件）、/var（日志 / 数据）、/usr（软件安装）、/home（用户目录）这些核心目录的作用没有区别。

查看系统日志: journalctl -p err -b 
-p err 表示只显示优先级为“错误”或更高级别（紧急，告急）的日志
-b 表示只显示本次启动以来的日志
