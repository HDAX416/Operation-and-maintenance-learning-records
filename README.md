# 运维自动化实战项目
> 基于 Linux + Docker + Shell 的一站式运维管理平台，整合服务部署、监控、备份、安全加固全流程

## 📌 项目简介
本项目是一套完整的运维自动化工具集，通过 Shell 脚本实现对 Docker 容器、MySQL、Redis 服务的一键管理，包含监控、备份、日志切割、安全巡检等功能，提升运维效率，保障服务稳定性。

## 🛠️ 技术栈
- 操作系统：Ubuntu WSL2
- 容器技术：Docker
- 数据库：MySQL 5.7、Redis
- 版本控制：Git + GitHub
- 自动化：Shell 脚本 + Crontab 定时任务
- 安全加固：Fail2ban、SSH 配置优化

## ✨ 功能模块
1.  **一键运维控制台**：集成服务启停、状态查看、备份、健康检查
2.  **数据库自动化备份**：定时备份 MySQL，支持压缩与过期清理
3.  **服务健康检查**：MySQL/Redis 存活检测，异常自动重启
4.  **系统资源监控**：CPU/内存/磁盘使用率监控，阈值告警
5.  **日志自动切割**：定时归档日志文件，防止磁盘占满
6.  **服务器安全巡检**：登录行为审计、端口与容器状态检查

## 🚀 快速开始
```bash
# 1. 启动一键运维控制台
./onekey_ops.sh

# 2. 手动执行系统监控
./sys_monitor.sh

# 3. 手动执行安全巡检
./security_check.sh
